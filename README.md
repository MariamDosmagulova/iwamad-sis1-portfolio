# Mariam Dosmagulova — Portfolio

**Live site:** https://mariamdosmagulova.github.io/iwamad-sis1-portfolio/

## About

This is my personal portfolio website that I made for SIS Assignment 1 in the Web Application Development course at KBTU.
It shows who I am, my skills, and the projects I built during the first weeks of the course, with links to each one.
I built it with plain HTML, CSS and JavaScript, and it has a dark/light mode switch and a contact form that checks what you type.

## Design decisions

1. **I used pink as my main colour.** Pink is one of my favourite colour, so I used it for headings, links and buttons. In dark mode the same pink was hard to read on the dark background, so I picked a lighter pink for the dark theme.
2. **I made the layout for phones first.** On a phone everything goes in one column so it is easy to read. On a wide screen the menu moves into one line, my photo goes next to my introduction, the projects become a 2 by 2 grid, and the form sits next to my contacts.
3. **I kept sizes and spacing simple.** I chose five font sizes and spacing in steps of 8px and saved them as CSS variables, so the whole page looks consistent. When I tested the site at 375px, the logo, menu and theme button did not fit in one row, so I put them under each other on small screens.
